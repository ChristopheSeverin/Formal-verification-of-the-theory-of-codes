# Undecidability of freeness for finitely generated subalgebras

Fix a field $K$. No algorithm decides whether the unital $K$-subalgebra of $K\langle a,b\rangle$ generated by a finite set $Y$ is isomorphic to a free algebra $K\langle B\rangle$ for some alphabet $B$. This holds even when $Y$ consists of words and differences of two words. The problem for arbitrary finite sets of polynomials is therefore undecidable over every computable field. The conclusion also holds for ring isomorphisms.

Manuscript by Astra 6.2, Lean formalization by Opus 5.5, supervised by Christophe Cordero. Date of discovery 26 November 2026. [PDF](manuscript/undecidability_of_subalgebra_freeness.pdf) · [LaTeX source](manuscript/undecidability_of_subalgebra_freeness.tex)

## Lean statement

Import `SubalgebraFreeness`. The algebra $K\langle a,b\rangle$ is `FreeAlgebra K Bool`, with $a$ = `false` and $b$ = `true`. A generator is a `WordSpec`. The specification `.inl w` denotes the word `w`, and `.inr (u, v)` denotes the difference $u-v$. For a list `Y` of specifications, `generated K Y` is the unital subalgebra generated by the denoted polynomials. An algorithm is a computable predicate in the sense of Mathlib, `ComputablePred`, on the encodable type `List WordSpec`. The alphabet `B` may lie in any universe. [Main theorem](lean/SubalgebraFreeness/MainTheorem.lean) · [Specifications and the block code](lean/SubalgebraFreeness/Encoding.lean)

```lean
theorem freeness_undecidable (K : Type v) [Field K] :
    ¬ ComputablePred fun Y : List WordSpec =>
      ∃ B : Type u, Nonempty (generated K Y ≃ₐ[K] FreeAlgebra K B)

theorem ring_freeness_undecidable (K : Type v) [Field K] :
    ¬ ComputablePred fun Y : List WordSpec =>
      ∃ B : Type u, Nonempty (generated K Y ≃+* FreeAlgebra K B)
```

`polynomial_freeness_undecidable` treats arbitrary finite sets of polynomials. It applies to any encodable type `P` of presentations with an interpretation `decode : P → FreeAlgebra K Bool`, provided each word and each difference of two words has a presentation computable from it. Over a computable field, presenting polynomials by lists of coefficients and words satisfies this hypothesis.

## Formalization choices

* **Turing machines.** The encoded machines are Mathlib's `TM0` machines. A step either writes a symbol or moves the head, and the machine halts where its transition is undefined. The instruction rules become $H_qc\to P_rd$ for a write, $H_qc\to cP_r$ for a move to the right and $H_qc\to U_rc$ for a move to the left. The halting rule $H_h\to C$ becomes $H_qc\to Cc$ for each pair $(q,c)$ on which the machine halts. The marking, sweeping and cleanup rules are those of the manuscript, and the initial state and the blank are `default`. `computation_free_iff` holds for every `TM0` machine and input.
* **Halting.** The manuscript closes with a diagonal argument for Turing machines. Lean uses Mathlib's halting problem for partial recursive programs instead, `ComputablePred.halting_problem`. Mathlib compiles partial recursive programs to `TM2`, then `TM1`, then `TM0` machines with finitely many reachable states. Applied to a universal program and restricted to these states, this gives one fixed machine with finitely many states and symbols (`Universal.machine`). It halts on the tape encoding of $m$ exactly when the program with code $m$ halts on $0$. Only the reset rule $LE\to LH_{q_0}w$ depends on $m$, through the binary digits of $m$. The map from a program to the list of generators is therefore primitive recursive.
* **Cycles.** An edge lies on an undirected cycle when a walk avoiding it joins its endpoints (`Rules.OnCycle`). A loop and two parallel edges thus give cycles of length one and two, as in the manuscript. `Rules.free_iff_forest` is the criterion for arbitrary rules. For the encoding the outdegree is at most one, and the cycles are the periodic vertices of the successor map (`Rules.Periodic`).

## Verification

Run `./verify.sh` from the repository root to build all libraries, run the audits and replay the declarations through the Lean kernel. The [audit](checks/Check.lean) prints the main statements and the definitions of the input format. It checks two small machines, one that halts at once and gives a nonfree algebra, and one that moves right forever and gives a free algebra. Its permitted axioms are `propext`, `Classical.choice` and `Quot.sound`.

To verify the exported proofs with the independent Nanoda kernel, run the following from the repository root.

```sh
lake build SubalgebraFreeness
mkdir -p build
lake env leanexport SubalgebraFreeness.MainTheorem -- SubalgebraFreeness.freeness_undecidable SubalgebraFreeness.ring_freeness_undecidable SubalgebraFreeness.polynomial_freeness_undecidable > build/undecidable-subalgebra-freeness.ndjson
lake env nanoda_bin proofs/undecidable-subalgebra-freeness/checks/nanoda.json
```
